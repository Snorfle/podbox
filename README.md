# PodBox

Podcast player for Xbox. This repo just hosts the privacy policy and terms of use that the Microsoft Store submission needs to link to.

## What the app does

Plays podcasts. Subscribes by RSS, OPML, or by picking something from a discover page that pulls from the Apple Podcasts charts. Supports private feeds with basic auth, variable speed (per-podcast), chapter navigation, auto-resume, download for offline.

Built for the controller. Right stick to move, LT/RT to seek. Works on Windows too, but the layout is tuned for ten-foot viewing.
